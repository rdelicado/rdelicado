## Sobre mí

Construyo páginas web para negocios de barrio — barberías, peluquerías, comercios locales — bajo la marca **[Karyllis](https://karyllis.com)**. No plantillas genéricas: cada web se hace a medida del negocio, con su copy, sus fotos y las herramientas que de verdad necesita (reservas online, formularios de contacto, reseñas).

Vengo de **[42 Málaga](https://42malaga.com)**, donde me formé de raíz en programación de sistemas: C, C++, redes, concurrencia y seguridad. Esa base es la que me permite no solo montar una web bonita, sino entender qué pasa por debajo — el servidor, la base de datos, el rendimiento y la seguridad.

- 🧱 **Stack web:** Astro · TypeScript · Tailwind CSS · Supabase (Postgres)
- ⚙️ **Base técnica:** C · C++ · Redes · Docker · Linux
- 🌍 **Disponible para** proyectos web freelance y colaboraciones

## 🏆 Trabajo destacado — Karyllis

Web completa para una barbería, construida con Astro + Tailwind y desplegada en Netlify. Incluye **sistema de reservas propio** (multi-servicio, con panel de gestión para el dueño protegido por PIN e instalable como app en el móvil), formulario de reseñas con aprobación manual y base de datos en Supabase.
